# Data Mining & Machine Learning Portfolio

Portofolio pembelajaran yang mendokumentasikan latihan praktis dalam pengambilan data, rekayasa fitur (*feature engineering*), dan pengujian hipotesis. Penjelasan notebook dan kode ditulis ulang untuk mendukung proses pembelajaran dan memastikan hasilnya dapat dijalankan kembali (*reproducibility*).

## Kursus 1: Dasar-Dasar Machine Learning

| **Modul** | **Fokus Pembelajaran** |
|---|---|
| [Membaca Data — Demo](https://github.com/Bright-Hikari/data-mining-and-machine-learning-portofolio/blob/main/01-machine-learning-foundation/01-reading-data-demo/README.md) | Membaca data SQLite menggunakan Pandas dan SQL |
| [Membaca Data — Praktik](https://github.com/Bright-Hikari/data-mining-and-machine-learning-portofolio/blob/main/01-machine-learning-foundation/02-reading-data-lab/README.md) | Melakukan kueri dan merangkum data bisbol |
| [Rekayasa Fitur](https://github.com/Bright-Hikari/data-mining-and-machine-learning-portofolio/blob/main/01-machine-learning-foundation/03-feature-engineering/README.md) | Encoding, transformasi, interaksi, dan fitur polinomial |
| [Pengujian Hipotesis](https://github.com/Bright-Hikari/data-mining-and-machine-learning-portofolio/blob/main/01-machine-learning-foundation/04-hypothesis-testing/README.md) | Hipotesis, nilai-p (*p-value*), kesalahan Tipe I dan Tipe II |

## Cara Menjalankan

1. Clone atau unduh repositori ini.
2. Instal dependensi dengan perintah: `pip install -r requirements.txt`.
3. Buka notebook menggunakan Jupyter Notebook atau VS Code.
4. Jalankan setiap sel secara berurutan dari atas ke bawah. Pastikan folder `data/` tetap berada di lokasi semula.

## Catatan

- Repositori ini merupakan portofolio pembelajaran, bukan reproduksi resmi dari materi kursus.
- Konsep kursus dirangkum menggunakan kata-kata sendiri. Cantumkan sumber kursus dan dataset yang digunakan jika diperlukan.
- Publikasikan dataset dan materi kursus hanya jika izin distribusinya memperbolehkan.
