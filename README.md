# Data Mining & Machine Learning Portfolio

Learning portfolio documenting practical exercises in data retrieval, feature engineering, and hypothesis testing. Notebook explanations and code are rewritten for learning and reproducibility.

## Course 1: Machine Learning Foundation

| Module | Focus |
|---|---|
| [Reading Data — Demo](01-machine-learning-foundation/01-reading-data-demo/README.md) | Reading SQLite data with Pandas and SQL |
| [Reading Data — Lab](01-machine-learning-foundation/02-reading-data-lab/README.md) | Querying and summarizing baseball data |
| [Feature Engineering](01-machine-learning-foundation/03-feature-engineering/README.md) | Encoding, transformations, interactions, polynomial features |
| [Hypothesis Testing](01-machine-learning-foundation/04-hypothesis-testing/README.md) | Hypotheses, p-values, Type I and Type II errors |

## How to run
1. Clone or download this repository.
2. Install dependencies: `pip install -r requirements.txt`.
3. Open a notebook in Jupyter Notebook or VS Code.
4. Run cells from top to bottom. Keep the `data/` folders in their current locations.
