# Reading Data — Demo

Membaca data dari SQLite menggunakan sqlite3, SQL, dan Pandas. Notebook: `reading_data_demo.ipynb`. Dataset: `data/classic_rock.db`.

## Tujuan pembelajaran
- Memahami konsep utama materi.
- Menjalankan kode dan membaca output.
- Menuliskan interpretasi dan kesimpulan dengan bahasa sendiri.

## Cara menjalankan
Buka notebook di Jupyter Notebook atau VS Code dan jalankan sel dari atas ke bawah. Instal dependency dari `requirements.txt` di root repository.
